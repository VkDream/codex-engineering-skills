# Codex 规则与六角色 Skill 分享包

一套面向 Windows / Codex Desktop 的工程协作规则：日常任务直接推进，需要职责隔离时再使用“总监、诊断、开发、审查、修复、验证”六角色接力。

本文件夹是独立分享副本，不包含作者的真实工程、账号配置、聊天记录或知识库历史；不是一键安装器，也不是 OpenAI 官方产品。

## 文件内容

| 目录 | 内容 |
|---|---|
| rules | 全局工程规则模板 |
| knowledge-base | 知识库入口、治理规则及一个未启用的项目模板 |
| skills | 六角色 Skill、路由 Skill、必要引用和两个辅助脚本 |
| optional-config | 可选的并发与子智能体配置示例 |

重点保留：授权边界、真实证据与 UNKNOWN、最小完整修改、独立审查、聚焦验证、回包字段校验、续页防重复和进程所有权。规则不能保证模型永远正确，也不能代替真实验收。

## 使用前做三件事

1. 先阅读规则，按自己的工程边界选择使用。不要直接覆盖现有 AGENTS.md 或 config.toml；有已有规则时先比较、备份并合并。默认禁用 Git 的规则也需要使用者了解并按自己的授权政策决定。
2. 把下面四种占位符替换成自己环境的真实位置，然后检查引用。占位符不会由 Codex、PowerShell 或 Node 自动展开。
3. 根据当前客户端支持情况安装 Skill；先做小任务验证，再明确启用六角色接力。仅复制文件不会创建角色任务或启用任何外部权限。

| 占位符 | 要替换的值 |
|---|---|
| {KB_ROOT} | 知识库根目录，例如 C:\ExampleKB |
| {SKILLS_ROOT} | 七个 Skill 文件夹安装后的共同父目录 |
| {SKILLS_ROOT_URI} | 同一目录的绝对 file URL，例如 file:///C:/ExampleSkills；含空格等字符需正确编码 |
| {GLOBAL_AGENTS} | 实际生效的全局 AGENTS.md 文件的绝对路径 |

先替换 {SKILLS_ROOT_URI}，再替换其余占位符。只在本包副本中替换，不要对整台电脑执行批量替换。knowledge-base 的内容放在选定的知识库根目录；rules/GLOBAL_AGENTS.md 是供合并的模板，不会因该文件名自动生效。

## 安装位置与运行条件

按 [OpenAI 当前 Skill 文档](https://developers.openai.com/codex/skills)，本地 Skill 可放在项目的 .agents/skills，或用户目录下的 .agents/skills。复制 skills 里面的七个文件夹，保留各自 SKILL.md、references、scripts 与 agents 结构；不要套一层导致入口丢失，也不要同时重复安装同名副本。企业或已有自定义宿主以实际加载位置为准。

普通任务可只使用所需规则；六角色自动接力还要求宿主实际暴露创建任务、读取任务和发送消息的接口。没有这些工具时，只能参考流程，不能声称自动派发已完成。MCP、浏览器工具、第三方插件和模型订阅均不随本包提供。

当前回包脚本要求 Windows 绝对 MASTER_RUN 路径；macOS/Linux 的完整接力尚未适配验证。Node.js 用于回包辅助模块；Python 和 headroom-ai 仅用于可选 Headroom 评估，不是普通规则阅读的必装项。

optional-config 是参考设置，不应整份替换 config.toml。模型表与子智能体配置表达作者的参考偏好，不证明接收者有相同模型、Fast 服务层或并发能力。并发 8 是上限，不是每次必须开 8 个；实际更低的宿主限制优先。确认本机版本支持字段和代理配置加载方式后再合并，配置文件变动按客户端要求重启生效。无需为了阅读本分享包中断正在运行的任务。

DSH 的模型由使用者自行选择，本包不修改 DSH，也不把 Codex 模型配置移植到 DSH。
